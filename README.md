## Topics explored

- Input, Processing, Output, Storage (IPOS)
- Hardware and software classification
- Terminal commands and file management
- Flags, pipes and package managers
- Operating system responsibilities, processes, paths and permissions
- Compilers vs interpreters
- Binary, decimal and hexadecimal number systems
- ASCII and UTF-8 text encoding
- Git version control and GitHub collaboration
- Computer networks, DNS, protocols and client-server model

---

## How to run the number converter

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive decimal number and the program will show its binary and hexadecimal form.
