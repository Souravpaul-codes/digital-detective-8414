## 4. My understanding

### Task 1.1 — IPOS trace: Typing and saving a document

| Stage | What happens | Hardware / component |
|-------|-------------|---------------------|
| Input | I type text using the keyboard | Keyboard |
| Processing | The CPU processes each keystroke and the text editor application formats and displays the text | CPU, RAM |
| Output | The typed text appears on the screen in real time | Monitor / display |
| Storage | When I press Ctrl+S, the file is saved to the SSD | SSD (solid-state drive) |

The activity starts when I press keys on the keyboard (input). The CPU processes each keystroke and sends the character to the text editor running in RAM (processing). The text editor shows the character on my screen (output). When I save, the file is written to permanent storage on the SSD (storage).
